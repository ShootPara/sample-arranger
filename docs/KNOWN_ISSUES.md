# Known gaps at usable delivery

Updated2026-11-04. Full intended scope is retained in REQUIREMENTS.md; unfinished
features are not presented as completed or silently removed from the product.

Actual user listening feedback describes the current music as nice but reminiscent
of dungeon-crawler music. More useful variation across future requested generations
is an objective, not a new delivery blocker or broad test program. See FEEDBACK.md.

- The owner has now authorized live AI. The app-owned broker adapter, protected
  connection dialog and AI plan UI/CLI are implemented. Dedicated server enrollment
  and one live request remain blocked by the unavailable authenticated administrative
  session, not missing user permission. See AI_SETUP.md. Local HTTP fixtures do not
  establish a live Trifecta connection.
- RX10 De-click failed its bypass-state validator case and is not fully compatible.
  A historical real-loop/preset job `57f35953-881b-4abc-ac1a-d95c7db0d4a1` measured
  approximately−91dB. That historical near-silent output is unresolved; other audible
  fixture/replay tests do not establish that this job was fixed.
- Offline routing supports sidechains, multiple buses and automation. Continuous
  playback currently supports a narrower persistent three-part/selected-bus/effect
  chain, not arbitrary persistent routing graphs or simultaneous output-bus mixing.
- Continuous buffers/spool and command/plugin memory have bounds. A combined cap
  across concurrent commands is unfinished. The rejected shared named-job approach
  returned Windows access denied; no OS security/privacy setting was weakened.
- Existing two-hour runs used pinned copied builds; do not infer physical acoustic
  gaplessness or current-code acceptance from an older run. Own-process synthetic
  WASAPI loopback is Windows-engine evidence, not microphone/hardware capture.
- Library key/role hints, tempo heuristics and conservative layered arrangements need
  musical review. Rich phrase transitions, measured downbeats/harmonic analysis,
  more styles/sounds and lock-aware AI phrase assembly remain incomplete.
- Composed notes/sections/harmony/rhythm have protections. Audio section locks,
  routing crash-draft recovery, scrub/playhead/meters and full timeline automation
  integration remain incomplete. Native editor vendor/DPI/focus behavior varies.
- Narration placement/ducking and output levels are measured; human intelligibility,
  delivery mastering profiles and broad listening/accessibility acceptance remain.
- Real MAGIX pack variants await owner examples. Actual instrument compatibility is
  per plugin, never established by scanning or a fixture alone.
- Local deployment works without elevation. Clean-machine/signed installer and
  complete binary redistribution/source/notices review are unfinished. Public
  source can be published separately; the personal Windows bundle is not cleared
  for public binary redistribution.

Normal job folders are retained; optional temporary normal sessions differ from
disposable continuous audio. Plugins/Windows may have their own caches. There is no
unsupported guarantee that all third-party data is erased.
